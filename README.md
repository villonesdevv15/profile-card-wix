# ProfileCard - Personal Portfolio

ProfileCard is a responsive, interactive personal portfolio website showcasing an "About Me" profile card complete with custom styled elements, audio player, social links, and entrance animations.

---

## Features

* **Responsive Layout:** Adaptive split-card grid design supporting desktop and mobile devices
* **Custom Typography & Design:** Custom Google Fonts (`Jost`, `Montserrat`, `Patrick Hand`, `Caudex`) and gradient backgrounds
* **Interactive Audio Player:** Custom JavaScript audio control interface with play/pause and seek functionality
* **CSS Animations:** Smooth entrance animations including fade-ins, keyframe bounces, and wiggles

---

## Prerequisites

* Any modern web browser (Google Chrome, Mozilla Firefox, Safari, Edge)
* A local development server or extension (e.g., VS Code Live Server) to serve audio assets smoothly
